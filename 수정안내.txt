배관119케어.co.kr 상담 전용 홈페이지 관리 안내

[사이트 역할]
- baegwan119care.kr: 공식 대표 홈페이지, 시공사례, 서비스·지역·비용 안내
- baegwan119care.co.kr: 전화·사진 문자 상담 전용 보조 사이트
- co.kr 전체에는 noindex 신호를 적용해 kr과 검색 노출이 경쟁하지 않게 구성

[가장 자주 수정하는 파일]
- index.html: 화면 문구, 전화번호, 버튼, 색상
- vercel.json: 검색엔진 noindex 응답 헤더
- robots.txt: 검색로봇 접근 설정

[수정 방법]
1. index.html을 메모장 또는 Visual Studio Code로 엽니다.
2. 원하는 문구를 수정하고 저장합니다.
3. 미리보기_co_kr.cmd를 더블클릭해 화면을 확인합니다.

[압축파일을 처음 받은 경우]
1. GitHub_원본_준비.cmd를 더블클릭합니다.
2. 같은 위치에 baegwan119care-GitHub 폴더가 자동으로 만들어집니다.
3. 앞으로는 그 폴더의 index.html을 수정합니다.
4. 그 폴더 안의 미리보기_co_kr.cmd와 배포_co_kr.cmd를 사용합니다.

[배포 방법 A - GitHub clone 폴더인 경우]
1. 배포_co_kr.cmd를 더블클릭합니다.
2. GitHub 로그인 창이 뜨면 로그인합니다.
3. Vercel과 GitHub가 연결되어 있으면 자동으로 배포됩니다.

[배포 방법 B - 압축파일로 받은 폴더인 경우]
1. Node.js가 설치되어 있어야 합니다.
2. 내일_베르셀_배포.cmd를 더블클릭합니다.
3. Vercel 로그인과 프로젝트 선택 안내에 따라 진행합니다.

[검색 정리 후 직접 해야 할 일]
- Google Search Console의 baegwan119care.co.kr 속성에서 홈페이지 URL 검사를 실행합니다.
- 색인 생성 요청은 하지 않아도 됩니다. 새 noindex를 읽도록 며칠 기다립니다.
- baegwan119care.kr 속성에서는 홈페이지 색인 생성을 요청합니다.
- 네이버 블로그와 당근 비즈프로필의 홈페이지 링크는 baegwan119care.kr로 통일합니다.
